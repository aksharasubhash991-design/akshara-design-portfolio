AKSHARA SUBHASH — CREATIVE PORTFOLIO WEBSITE

VIEW LOCALLY
1. Download and extract this ZIP.
2. Open the extracted folder.
3. Double-click index.html to open in a browser.

CUSTOMIZE BEFORE PUBLISHING
- In index.html, replace your.email@example.com with your real email.
- Add your LinkedIn and Instagram links in the contact section.
- Add your actual CETAA Day video link or thumbnail if you want the video work showcased directly.
- You can add more original images to assets/ and create additional project cards by copying an existing project card in index.html.
- Keep index.html, style.css, script.js and assets/ together.

PUBLISH
- Upload the extracted folder to Netlify Drop, or push it to GitHub and import it into Netlify/Vercel.
- Do not upload only index.html; the assets folder and CSS/JS files are required.

This website includes the original artwork supplied in the conversation.
